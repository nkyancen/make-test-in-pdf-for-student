Project for make various test tasks in PDF format.
Test questions are located in the "data_base" folder.
The main TeX and data files for creating the final PDF is located in the "tex_files"" folder, the rest are in the "tex_files/data" folder.

Проект для создания различных тестовых заданий в формате PDF.
Вопросы тестов находятся в папке «data_base».
Основной TeX и data файл для создания итогового PDF находится в папке «tex_files», остальные - в папке «tex_files/data».
